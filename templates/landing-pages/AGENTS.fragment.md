# Trecho para integrar ao AGENTS.md do projeto consumidor

Ao criar, reformular ou auditar uma landing page:
1. Leia `docs/landing-page-playbook.md` (copiado do repositório Skills Bryan ou disponibilizado com caminho acessível), `BRIEF.md`, `DESIGN.md` e instruções existentes.
2. Leia as skills relevantes instaladas; nunca presuma que o nome na documentação implica skill carregada. Use ferramentas de browser para testar; não invente evidências.
3. No modo DIREÇÃO, apresente duas alternativas antes da implementação. No COMPLETO, execute todas as fases. No AUDITORIA, limite o escopo.
4. Mantenha `AUDIT.md` com Rxx → local → teste → evidência → status e `LESSONS.md` após feedback.
5. Não misture dados de clientes/propostas em repositórios públicos, nem publique sem autorização.
6. Reporte pendências e diferencie claramente `não verificado` de `aprovado`.

Este é um fragmento, não substitui o AGENTS.md existente. Preserve as demais instruções e hierarquia de prioridades.
